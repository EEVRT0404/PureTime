# 🕒 PureTime

PureTime 是一款極簡的數字時鐘應用程式，專注於提供乾淨、現代化的時間顯示。

它以 24 小時制 為主，並根據電腦的 應用程式色彩模式（深色／淺色）自動切換外觀。



### 💻 運作方式

以裝置日期進行設定



### ✨ 外觀特色

24 小時制時間顯示

日期顯示

自動切換深色／淺色模式

簡潔、無干擾的介面設計



### 🧩 技術細節

PWA:安裝於電腦

HTML：結構化頁面

CSS：Flexbox 置中、深淺色模式切換、字體樣式

JavaScript：即時更新時間（每秒刷新）
